# Clutch Pro – Manual Car Driving 3D
Push this folder to a GitHub repo (or upload the zip contents). Actions → "Build APK" → download artifact `ClutchPro-debug-apk` → install `app-debug.apk`.
Game code lives in `app/src/main/assets/` (index.html, game.js, physics.js, three.min.js).
Desktop test: open `app/src/main/assets/index.html` in Chrome (W/S gas/brake, Shift clutch, 1-5/R/N gears, A/D steer, E engine, Space handbrake, H horn, C camera).
